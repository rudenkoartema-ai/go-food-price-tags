# GO FOOD — Генератор цінників

Внутренний веб-инструмент Coffee Go: сотрудник вводит названия, цены, формат (большой / малый) и количество, программа раскладывает ценники по листам A4 и отдаёт один PDF для печати.

Это статический сайт без сервера: вся работа (раскладка и сборка PDF) выполняется в браузере, ничего не отправляется наружу, платных сервисов нет.

## Быстрый старт

```
node tools/build_html.js     # собрать dist/index.html (один самодостаточный файл)
node --test tests/core.test.js
```

Готовый `dist/index.html` можно открыть прямо с диска или выложить на любой статический хостинг.

## Публикация на Render (отдельный репозиторий!)

1. Создайте **новый пустой приватный репозиторий**, залейте туда этот проект. Рабочую программу в другом репозитории не трогаем.
2. Render: New + → Blueprint → выберите этот репозиторий. `render.yaml` уже настроен: Static Site, сборка `node tools/build_html.js`, публикация `dist`.
3. Постоянная ссылка Render и есть адрес для сотрудников. Дальше каждый коммит в `main` публикуется автоматически.

## Что где лежит

| Путь | Назначение |
|---|---|
| `src/config.js` | **Все размеры в мм**: ценники, сетка, зазоры, линии реза, смещение печати `printOffset`, лимиты |
| `src/layout.js` | Раскладка по листам |
| `src/validate.js` | Проверка данных, сообщения на украинском |
| `src/scene.js`, `src/text.js` | Сборка одного ценника: название, цена, ГРН |
| `src/pdf.js` | Собственный генератор PDF (векторный, без библиотек) |
| `src/assets.js` | Сгенерированная графика: штрих, логотип, контуры букв (не править руками) |
| `tools/build_assets.py` | Пересборка `assets.js` из эталонов `assets/reference/*.png` |
| `ui/` | Интерфейс |
| `tests/` | Автотесты и проверка PDF |
| `samples/` | Контрольные PDF |
| `docs/INSTRUKTSIYA.md` | Инструкция для сотрудников |

## Размеры

Размеры не заданы в исходных файлах, поэтому измерены по эталонным листам A4 (в предположении, что картинка = лист A4 без полей):

| Формат | Размер ценника | Сетка | Источник |
|---|---|---|---|
| Большой (L) | 92 × 88 мм | 2 × 3 = 6 | лист «Чіабата», измерено по пикселям |
| Малый (S) | 83 × 65 мм | 2 × 4 = 8 | лист «Еклер / Шокосендвіч…», измерено по пикселям |

Большие ценники в образцах «Круасан курка сир» чуть крупнее (95 × 90), то есть листы в образцах отличаются масштабом. Если размеры на ваших напечатанных ценниках другие, меняйте `tagW`, `tagH`, `cellW`, `cellH` в `src/config.js` (один раз) и пересобирайте. Для подгонки под принтер используйте калибровочный лист и `printOffset`.

## Ограничения первой версии

- Буквы и цифры — это ваши настоящие кистевые буквы, векторно извлечённые из присланных образцов (не шрифт-аналог). Є, Ї, Ґ в образцах не встречались — они достроены из соседних букв и могут слегка отличаться от рукописного оригинала (Ь, Щ, 0 и дефис взяты из настоящих образцов). Латиница и символы, которых нет в образцах, не поддерживаются (программа покажет сообщение). Подпись в логотипе — вариант «BRAND by COFFEE GO»; в образце с «ЕКЛЕР» на логотипе было «ШВИДКО І СМАЧНО» (это одна из двух версий логотипа).
- Цвета PDF в RGB. Если типография требует CMYK, конвертацию лучше делать ею или отдельным шагом.
- Без припуска под обрез (bleed): ценники по краям чёрные, поэтому при резке на гильотине допуск ~1 мм виден. Для ручной резки по пунктиру это не проблема.
- Цена только целые гривны.
